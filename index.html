Configuration
FortiGate config files
firewall-policy.conf .conf
# Allow LAN to WAN (HTTP/HTTPS)
config firewall policy
  edit 1
    set name "LAN_to_WAN"
    set srcintf "internal"
    set dstintf "wan1"
    set action accept
  next
end
vpn-ipsec.conf .conf
# IPsec Phase 1
config vpn ipsec phase1-interface
  edit "SiteB_VPN"
    set interface "wan1"
    set ike-version 2
    set peertype any
  next
end
interfaces.conf .conf
# Internal LAN interface
config system interface
  edit "internal"
    set ip 192.168.1.1 255.255.255.0
    set allowaccess ping https ssh
  next
end

Step-by-Step
Configuration walkthrough
01

Initial FortiGate setup & interface configuration

Connected to FortiGate via console cable. Set management IP, configured WAN and LAN interfaces with appropriate subnets, and verified connectivity.

02

Firewall policy & NAT rules

Created zone-based policies for LAN→WAN, DMZ→WAN, and inter-zone traffic. Configured port address translation (PAT) on WAN interface for outbound traffic.

03

IPsec VPN tunnel configuration

Configured site-to-site IKEv2 tunnel with phase 1 (encryption AES-256, hash SHA-256) and phase 2 selectors. Verified tunnel establishment via diagnose CLI.

04

Security profiles & IPS deployment

Applied IPS signature packages, enabled web filtering by category, attached antivirus profile, and bound all profiles to relevant firewall policies.

05

Testing, validation & traffic analysis

Ran connectivity tests across all zones, triggered test IPS events to validate blocking, and captured FortiGate logs confirming expected policy behavior.
